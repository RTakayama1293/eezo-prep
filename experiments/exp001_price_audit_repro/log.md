# exp001: 価格精査一覧の再現

## 目的
`20260424_DATA_EEZO価格精査一覧.xlsx`（70%たたき台）を、推定を排除した形でパイプライン再現する。

## サンプル仕入先（全分岐を網羅）
| 仕入先 | 送料区分 | 送料テーブル | 検証ポイント |
|--------|---------|-------------|-------------|
| 梅屋 | 産直別途 | 温度帯型 | 自動引当→売上原価3322が添付と一致 |
| トワ・ヴェール | 送料込 | 不要 | 仕入送料0・消費者送料を売上に算入して計算継続 |
| 小樽水産加工 | 産直別途 | 未格納 | 仕入送料・売上原価が空欄＋要確認 |
| ベターデイズ | 産直別途 | サイズ型 | サイズ不明で自動引当不可・要確認 |
| NIKI Hills | 産直別途 | 未格納 | 酒類疑い→税率空欄、税抜換算停止 |

## 実行
```bash
bash experiments/exp001_price_audit_repro/run.sh
```

## 結果（要点）
- 梅屋A: 売上原価 1912+1410=3322（添付一致）。売上=2000+1090.91=3090.91、粗利 -231.09（売上−原価、決済手数料は販管費で粗利外）。
- 推定禁止が機械的に作動: 送料未格納・酒類疑い・税区分不明は空欄＋要確認に集約。
- 商品数7 / 要確認あり6。
