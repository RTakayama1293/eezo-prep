# Coding Style Rules

## Python
- 型ヒント必須
- docstring必須（Google形式）
- インデント: スペース4つ
- f-string優先
- 1ファイル500行以下

## 命名規則
- 変数/関数: snake_case
- 定数: UPPER_SNAKE_CASE
- 業務語の変数名は日本語可（採算ロジックの可読性優先）

## インポート順序
1. 標準ライブラリ
2. サードパーティ（openpyxl）
3. ローカルモジュール

## 決定論の置き場所
- 採算・送料・整形ロジックは `src/` に集約。
- ルール変更（税率・送料・無料ライン等）は `config/` で値として管理し、コードに直書きしない。
