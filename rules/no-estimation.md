# 推定禁止ルール（最重要）

このリポジトリの最優先ルール。見積に書いてある事実だけを転記し、無ければ空欄＋要確認とする。

## 区分

| 区分 | 扱い |
|------|------|
| 転記（extract） | 見積記載の事実のみ写す。無ければ空欄 |
| 決定論導出（derive） | 情報を創作しない変換のみ許可（税込÷(1+税率)、tags組成、vendor固定、温度帯→常温/クール対応） |
| 手入力（input） | title・productType・想定販売価格・画像URL等。勝手に確定しない |
| 禁止 | 下記「禁止する推定」 |

## 禁止する推定

- 温度帯を商品名・商品種別から推定する
- 仕入送料を他社テーブルやサイズ仮定で仮置きする（旧・価格精査一覧の「小樽水産→ヤマト80関西」方式は廃止）
- 税込/税抜が不明なのに片方を仮定して換算する
- 価格未記載（オープン価格・時価・要相談）を「だいたい」で埋める
- 「〇〇円〜」から自動で最低値を採用する

## 許可する自動導出（推定ではない）

- 税込→税抜（税率が判明している場合のみ）
- vendor = `EEZO（エエゾ）` 固定、status = `DRAFT` 固定
- tags = 温度帯（冷蔵→チルド）＋仕入先＋産地
- 税率: 見積明記＞明確な食品8%（フラグ付）。酒類疑いは確定せず空欄＋要確認

## 空欄が出たら

空欄は「未取得の事実」として `要確認メモ` と要確認一覧に必ず積む。空欄を放置・黙殺しない。
