# 抽出ルール（見積 → 中間CSV）

Claudeが各仕入先ディレクトリの見積を読み、`processed/{仕入先}_products.csv` へ転記する際のルール。
**書いてある事実だけ。無ければ空欄。推定で埋めない。**

## 商品中間CSVの列と転記方針

| 列 | 転記方針 |
|----|----------|
| 仕入先 | ディレクトリ名（カタカナ正式表記） |
| 出典ファイル | 読んだ見積のファイル名 |
| 商品名_見積準拠 | 見積記載の商品名そのまま |
| EEZO商品名 | 既存の対応名があれば。無ければ空欄（登録時に確定） |
| 規格内容 | 「シュー8個」「12品」等、見積記載の構成 |
| 温度帯 | 常温/冷蔵/冷凍。**記載が無ければ空欄**（商品名から推定しない） |
| 仕入単価_値 | 数値のみ。カンマ・円記号は除去 |
| 仕入単価_税区分 | **税込 / 税抜 / 不明** を必ず記載。見積の表記を確認 |
| 参考上代_値 / _税区分 | あれば。オープン価格は空欄＋備考 |
| 箱代等_値 / _税区分 | 箱代・発送手数料が別記の場合のみ。税区分も記載 |
| 仕入送料区分 | **送料込 / 産直別途 / 不明** |
| 内容量・賞味期限・保存方法・発注ロット・リードタイム・JANコード・アレルゲン・産地 | 見積記載のみ。無ければ空欄 |
| 商品特徴 | 説明文の素材になる記述があれば |
| 税率_明記 | 見積に税率明記がある場合のみ 8 or 10。無ければ空欄 |
| 想定販売価格_税込 | 現行Shopify価格 or 目標価格。手入力。**創作しない**（不明なら空欄） |
| 備考 | 支払条件・在庫・特記事項 |

## 価格の扱い

- 通貨記号（円・¥・￥）、桁区切りカンマ、スペースは除去して数値化。
- **税込/税抜の判別は最重要**。見積に「税込」「税抜」「+税」「(本体)」等の表記を確認し `_税区分` に記載。
  どちらか判別できない場合は「不明」とする。スクリプトは不明を換算せず空欄＋要確認にする。
- 「オープン価格」「時価」「要相談」→ 値は空欄、備考に明記。
- 「〇〇円〜」→ 値は空欄＋備考（最低価格を採るかは人が判断）。**自動で最低値を採らない**。

## 温度帯

- 見積記載の常温/冷蔵/冷凍をそのまま。チルド表記は冷蔵扱い。
- 記載が無ければ空欄。**商品種別からの推定はしない**（要確認に回す）。

## 税率（スクリプト側の決定論ルール／参考）

抽出時は `税率_明記` に明記分だけ入れればよい。スクリプトは次で決定する:

| 条件 | 税率 | 扱い |
|------|------|------|
| 見積に明記（8 or 10） | 明記値 | フラグなし |
| 明記なし＋酒類疑い（酒/日本酒/ワイン/ml表記 等） | 空欄 | 要確認（8か10か） |
| 明記なし＋上記以外 | 8（食品前提・仮適用） | 要確認フラグ付き |

酒類は8/10の判断が実害に直結するため、**自動で確定させず空欄＋要確認**にする。

## 仕入送料区分の判定

| 見積の記述 | 区分 |
|------------|------|
| 「送料込」「価格に含む」「産直送料込み」 | 送料込 |
| 「送料別途」「別紙送料表」「産直・送料別」 | 産直別途 |
| 記述なし・判断不能 | 不明（空欄＋要確認） |

「産直別途」で送料見積が未受領の場合は、`_shipping.csv` を作らない。
→ スクリプトが「送料見積が未格納。空欄（要取得）」と要確認に出す。
