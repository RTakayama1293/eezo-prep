# 送料の二層モデルと採算計算

## 二層の送料

| 層 | 何の送料か | 出所 | 採算への効き方 |
|----|-----------|------|---------------|
| 仕入送料 | 我々が支払う配送コスト（産直なら仕入先→消費者） | 各仕入先の送料見積 | 変動原価／送料P&Lのコスト側 |
| 消費者負担送料 | 我々が消費者から受け取る送料（公開ポリシー） | config/eezo_policy.json（出典: 公開URL） | 送料P&Lの収入側 |

公開ポリシー（消費者負担送料）が**正**。スナップショットは実行前に出典URLと突き合わせ、相違があれば config を更新する。数値の据え置き禁止。

## 仕入送料の引き当て（基準地域着）

| 送料体系 | 引き当て |
|----------|----------|
| 送料込 | 0 |
| 産直別途 ＋ 温度帯型テーブル | 温度帯（常温/冷蔵・冷凍）×基準地域で引き当て |
| 産直別途 ＋ サイズ型テーブル | **自動引当しない**（荷姿サイズが見積に無いため）。手動・要確認 |
| 産直別途 ＋ テーブル未受領 | **空欄＋要確認**（要取得） |
| 不明 | 空欄＋要確認 |

サイズ型（ヤマト型）は荷姿サイズが確定して初めて送料が決まる。見積にサイズが無い段階で仮置きすると推定になるため、空欄＋要確認に倒す。

## 採算計算式（基準地域＝関西着が既定）

```
税抜化:
  仕入単価_税抜   = 税区分が税抜ならそのまま / 税込なら ÷(1+税率/100) / 不明なら空欄
  箱代等_税抜     = 同上
  想定販売価格_税抜 = 想定販売価格_税込 ÷ (1+税率/100)   ※税率不明なら空欄

変動原価合計_税抜 = 仕入単価_税抜 + 箱代等_税抜 + 仕入送料_基準地域
  （仕入単価か仕入送料のどちらかが空欄なら → 空欄＋要確認）

決済手数料 = 想定販売価格_税込 × 決済手数料率(既定3.25%)

商品粗利_税抜 = 想定販売価格_税抜 − 変動原価合計_税抜 − 決済手数料

送料P&L:
  通常時   = 消費者負担送料_基準地域 − 仕入送料_基準地域
  送料無料時 = 0 − 仕入送料_基準地域

総粗利:
  通常時   = 商品粗利_税抜 + 送料P&L(通常時)
  送料無料時 = 商品粗利_税抜 + 送料P&L(送料無料時)
総粗利率(通常時) = 総粗利(通常時) / 想定販売価格_税抜
```

いずれかの入力が空欄なら、その先の計算結果も空欄になる（推定で埋めない）。

## 採算フラグ（自動付与）

| フラグ | 条件 |
|--------|------|
| 商品粗利が赤字 | 商品粗利_税抜 < 0 |
| 通常時総粗利が赤字（逆ざや） | 総粗利(通常時) < 0 |
| 想定販売価格が参考上代を上回る | 販売_税抜 > 参考上代_税抜 |
| 単品で送料無料ライン到達 | 想定販売価格_税込 ≥ 送料無料ライン |

## 旧・価格精査一覧との違い（重要）

| 論点 | 旧シート（70%たたき台） | 本スキル |
|------|------------------------|---------|
| 送料未受領の扱い | ヤマト80関西で仮置き | 空欄＋要確認（仮置きしない） |
| 消費者送料 | 添付時点（無料ライン10,000円） | 公開URL最新（**15,000円**・地域別レート改定）を正とする |
| 採算式 | 変動コスト基準の粗利 | 決済手数料＋送料P&Lまで含む明瞭モデル |
| 税込/税抜不明 | 8%前提で換算 | 不明は換算せず空欄 |

数値が旧シートと一致しないのは、計算モデルを明瞭化したため（誤りではない）。
