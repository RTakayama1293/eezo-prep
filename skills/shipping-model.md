# 送料の二層モデルと採算計算

## 二層の送料

| 層 | 何の送料か | 出所 | 採算への効き方 |
|----|-----------|------|---------------|
| 仕入送料 | 我々が支払う配送コスト（産直なら仕入先→消費者） | 各仕入先の送料見積 | 変動原価／送料P&Lのコスト側 |
| 消費者負担送料 | 我々が消費者から受け取る送料（公開ポリシー） | config/eezo_policy.json（出典: 公開URL） | 送料P&Lの収入側 |

公開ポリシー（消費者負担送料）が**正**。スナップショットは実行前に出典URLと突き合わせ、相違があれば config を更新する。数値の据え置き禁止。

## 仕入送料の引き当て（基準地域着）

| 送料体系 | 引き当て |
|----------|----------|
| 送料込 | 0 |
| 産直別途 ＋ 温度帯型テーブル | 温度帯（常温/冷蔵・冷凍）×基準地域で引き当て |
| 産直別途 ＋ サイズ型テーブル | **自動引当しない**（荷姿サイズが見積に無いため）。手動・要確認 |
| 産直別途 ＋ テーブル未受領 | **空欄＋要確認**（要取得） |
| 不明 | 空欄＋要確認 |

サイズ型（ヤマト型）は荷姿サイズが確定して初めて送料が決まる。見積にサイズが無い段階で仮置きすると推定になるため、空欄＋要確認に倒す。

## 採算計算式（基準地域＝関西着が既定）

考え方は「**売上＝商品＋送料、原価＝商品＋送料**」のシンプルな1モデル。消費者からは送料を別途受け取り（送料別表示）、その送料収入で仕入送料コストを賄う（=送料は概ね行ってこい）。**決済手数料は販管費なので粗利には含めない**（参考列にのみ表示）。

```
税抜化:
  仕入単価_税抜   = 税区分が税抜ならそのまま / 税込なら ÷(1+税率/100) / 不明なら空欄
  箱代等_税抜     = 同上
  想定販売価格_税抜 = 想定販売価格_税込 ÷ (1+税率/100)          ※税率不明なら空欄
  消費者送料_税抜  = 消費者負担送料_基準地域 ÷ (1+送料税率/100)  ※送料税率=10%固定

売上原価_税抜 = 仕入単価_税抜 + 箱代等_税抜 + 仕入送料_基準地域
  （仕入単価か仕入送料のどちらかが空欄なら → 空欄＋要確認）

売上_税抜 = 想定販売価格_税抜 + 消費者送料_税抜          ← 消費者送料を収入として算入

粗利_税抜 = 売上_税抜 − 売上原価_税抜                    ← 決済手数料は引かない
粗利率   = 粗利_税抜 / 売上_税抜

送料無料時（消費者送料を受け取らない・ワーストケース）:
  粗利_送料無料時 = 想定販売価格_税抜 − 売上原価_税抜
  粗利率_送料無料時 = 粗利_送料無料時 / 想定販売価格_税抜

参考（粗利の外）:
  送料PL_通常時      = 消費者送料_税抜 − 仕入送料_基準地域   ← 送料が行ってこいかの確認用
  決済手数料_販管費   = 想定販売価格_税込 × 決済手数料率(既定3.25%)
  手数料控除後利益_参考 = 粗利_税抜 − 決済手数料_販管費
```

仕入送料は売上原価に**1回だけ**計上する（消費者送料は売上側で受けるので二重計上しない）。いずれかの入力が空欄なら、その先の計算結果も空欄になる（推定で埋めない）。

### 検算例（梅屋シューAセット相当）

| 項目 | 値 |
|------|----|
| 仕入単価_税抜 | 1,912 |
| 仕入送料(関西・税抜) | 1,410 |
| 売上原価_税抜 | 3,322 |
| 想定販売価格_税抜 | 2,000 |
| 消費者送料_税抜(クール関西 1,200÷1.1) | 1,090.91 |
| 売上_税抜 | 3,090.91 |
| **粗利_税抜** | **−231.09**（逆ざや） |
| 粗利率 | −7.48% |
| 決済手数料_販管費(参考) | 70.2 |

## 採算フラグ（自動付与）

| フラグ | 条件 |
|--------|------|
| 通常時粗利が赤字（逆ざや） | 粗利_税抜 < 0 |
| 送料無料時粗利が赤字 | 粗利_送料無料時 < 0 |
| 想定販売価格が参考上代を上回る | 販売_税抜 > 参考上代_税抜（送料が行ってこいの範囲なら誤差程度のことが多い・要判断） |
| 単品で送料無料ライン到達 | 想定販売価格_税込 ≥ 送料無料ライン |

## 旧・価格精査一覧との違い（重要）

| 論点 | 旧シート（70%たたき台） | 本スキル |
|------|------------------------|---------|
| 送料未受領の扱い | ヤマト80関西で仮置き | 空欄＋要確認（仮置きしない） |
| 消費者送料 | 添付時点（無料ライン10,000円） | 公開URL最新（**15,000円**・地域別レート改定）を正とする |
| 採算式 | 変動コスト基準の粗利 | 売上(商品＋消費者送料)−原価(仕入＋仕入送料)の粗利。決済手数料は販管費で粗利外 |
| 税込/税抜不明 | 8%前提で換算 | 不明は換算せず空欄 |

数値が旧シートと一致しないのは、計算モデルを明瞭化したため（誤りではない）。
