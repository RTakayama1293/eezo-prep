# data/raw（入力・編集禁止）

## 置き方
直下に出力フォーマットの型（`_OUTPUT_TEMPLATE.xlsx`）、その下に仕入先ごとのディレクトリ。

```
data/raw/
├── _OUTPUT_TEMPLATE.xlsx
├── 梅屋/
│   ├── 見積_0416.pdf
│   └── 送料見積.xlsx        # あれば
├── トワ・ヴェール/
│   └── 見積_20260411.pdf    # 送料込なら送料見積なし
└── 小樽水産加工/
    └── 見積.pdf             # 送料別途・未受領 → 仕入送料は空欄＋要確認
```

## ルール
- ディレクトリ名＝仕入先名（カタカナ正式表記）。
- ここのファイルは**絶対に編集しない**（rules/data-integrity.md）。
- 見積は社外秘。リポジトリはプライベートで運用すること。
